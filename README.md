# Neri, Inc.

Static Astro site for Neri, Inc. in Crete, Illinois. Tailwind CSS v4, with the contact form as a Vue 3 island using Flowbite-Vue.

```bash
npm install
npm run dev
npx astro build --timings
```

Preview pages send `noindex`. The contact form opens an email to neriinc@att.net until a hosted form endpoint is chosen.
